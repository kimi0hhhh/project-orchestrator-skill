## v5.0 OpenCode 版

- 运行时同源（runtime 早期即由 OpenCode 版构建脚本生成），主要差异在：
  - 子 agent 派发机制适配（OpenCode 的 agent/session 模型）
  - token 账本后端（usage.py 已内置 OpenCode session 读取路径）
  - skill 加载机制差异
- 目标：同一套角色契约与 SKILL.md 主体，仅平台适配层不同

## v6.0 通用版

- 抽出平台无关的「编排协议」：角色契约 schema、阶段状态机、门禁规则、参谋协议、分诊规则
- 平台适配层接口化：派发器（Agent tool / subprocess / 其他 agent 框架）、账本后端、看板
- 目标：一套协议，任意支持子 agent 派发与工具调用的编码 agent 皆可运行
