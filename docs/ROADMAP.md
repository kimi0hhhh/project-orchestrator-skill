## v4.4（已发布 · OpenCode 版）

- 新增 `scoring/` 评分尺：积木分（8 块静态检查）+ 项目分（三条线）+ 红绿验证 + UI 点击冒烟

- `20-closeout` 欠账台账 + S7 就绪清单第 5/6 项（含 retro 第 1 问必须带漏网数）
- `runtime/archive.py` 交付包归档
- **协议级变更**：门禁 `G-QA-02` 加运行时点击红线、新增工件编号 —— 另三实现待移植

## v4.3（已发布 · ZCode 版）

- 耗时账单：`/api/timetrack` + 看板「耗时账单」面板 + `cli.py time`
- 派发管家 `runtime/dispatch.py`（预检拒发 + 角色记忆回读 + 任务书落盘）
- 纪律入 SKILL：真并行派发、会签/返修 2 轮上限、上报税瘦身、验证规模上限、记忆卫生
- 新增轻模型角色 `backend-fast`
- 实测：3 路并行 vs 串行 **墙钟 −56%**（324s vs 745s），两臂门禁全绿零返工

## ~~v5.0 OpenCode 版~~ —— 已作为 v4.1 交付，编号未启用（以下为原始计划，保留备查）

- 运行时同源（runtime 早期即由 OpenCode 版构建脚本生成），主要差异在：
  - 子 agent 派发机制适配（OpenCode 的 agent/session 模型）
  - token 账本后端（usage.py 已内置 OpenCode session 读取路径）
  - skill 加载机制差异
- 目标：同一套角色契约与 SKILL.md 主体，仅平台适配层不同
