## 中文（推荐主用）

> 为 agent 开发工具设计的多 Agent 协作模式（编排协议）：1 个主 Agent 当项目负责人，6 个单责角色（产品/架构/前端/后端/组长/测试）加按需只读参谋，按 S0–S7 门禁流水线交付完整产品。单写手 · 单层编排 · 只读参谋 · 门禁不放水，附盲评实验数据与 2025–26 研究对照。ZCode 与 OpenCode 为前两个先行实现（本仓库先发布 ZCode 版），通用版规划中。

简短版（<100 字符）：

> 多 Agent 协作编排协议：项目负责人 + 6 单责角色 + 阶段门禁，单写手 + 只读参谋，附盲评实验数据

## English

> A multi-agent collaboration pattern (orchestration protocol) for agent dev tools: one agent as project owner, 6 single-accountability roles (PM/Architect/Frontend/Backend/Lead/QA) plus on-demand read-only advisors, delivering full products through an S0–S7 gated pipeline. Single writer · one-layer orchestration · read-only advisors · strict gates. Ships with blind-judged benchmarks and 2025–26 research grounding. ZCode & OpenCode are the first two implementations (this repo ships ZCode first); universal edition planned.

Short version:

> Multi-agent orchestration protocol: project owner + 6 single-accountability roles + stage gates. Single writer, read-only advisors, benchmark data included.
